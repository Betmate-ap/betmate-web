# BetMate Web

React frontend for the BetMate platform — Vite + React 19 + TypeScript + Apollo Client, deployed on Vercel.

> **Backend repo:** [betmate-api](https://github.com/Betmate-ap/betmate-api) — see its README for API setup and the staging URL.

---

## Local Development

### Prerequisites

- [Node.js](https://nodejs.org) (v20+)
- [betmate-api](https://github.com/Betmate-ap/betmate-api) running locally (or use the staging API)

### First-time setup

```bash
# 1. Install dependencies
npm install

# 2. Create your local env file
cp .env.example .env
# Edit .env if you want to point at the staging API instead of local
```

### Run

```bash
npm run dev
```

App is available at `http://localhost:5173`

---

## Environment Variables

| Variable       | Required | Description                             |
| -------------- | -------- | --------------------------------------- |
| `VITE_API_URL` | Yes      | GraphQL API endpoint — local or staging |

Staging API: `https://betmate-api-staging-staging.up.railway.app/graphql`

## Scripts

```bash
npm run dev          # Start dev server with HMR
npm run build        # Type-check + production build
npm run preview      # Preview production build locally
npm run lint         # ESLint
npm run lint:fix     # ESLint with auto-fix
npm run format       # Prettier check
npm run format:fix   # Prettier write
npm run type-check   # TypeScript check only (no build)
```

## Project Structure

│   └── mutations/   # GraphQL mutation documents

## Deployment

This app is deployed on **Vercel**. Every merge to `main` auto-deploys to the staging environment. Every PR gets its own preview URL automatically.

| Environment | Trigger         | URL                            |
| ----------- | --------------- | ------------------------------ |
| Preview     | Every PR        | Auto-generated by Vercel       |
| Staging     | Merge to `main` | https://betmate-web.vercel.app |
